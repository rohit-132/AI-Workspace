# AI Workspace Pro

AI Workspace Pro is a modern admin dashboard built using React, Vite, and Tailwind CSS. It provides a clean, responsive, and user-friendly interface for managing dashboards, user profiles, tables, forms, charts, and other administrative features.

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- TypeScript
- React Router

## Features

- Responsive Dashboard
- User Profile
- Dark & Light Mode
- Forms
- Tables
- Charts
- Authentication Pages

## Installation

Go to the project folder:

```bash
cd free-react-tailwind-admin-dashboard
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Open your browser:

```
http://localhost:5173
```
